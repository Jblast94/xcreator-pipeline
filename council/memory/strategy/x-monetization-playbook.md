# X Monetization Playbook (v1 — 2026-09-01)

## Goal
First $1 from X within 30 days. Then scale impressions → Original Content Rewards + affiliates.

## Phase 0 — Eligibility (do this week)
- [ ] Confirm X Premium (not Basic). $8/mo web. Needed for monetization + higher Grok limits.
- [ ] Hit 500 verified followers. Verified = Premium subscribers. Grow via agent/AI niche replies + original threads.
- [ ] Accumulate 500k verified Home Timeline impressions in 90 days (replies don't count toward the bar).
- [ ] Account 18+, in a supported country, no policy strikes.
- [ ] Enroll in Creator Studio → Original Content Rewards (opens Sep 8 for existing members; check eligibility anytime).

## Phase 1 — Content engine (daily)
Post 2–4x/day. Mix:
- 40% original analysis: "I built X with Y agents, here's the cost/result"
- 30% trend intel: council-scored trends + one actionable take
- 20% affiliate: one tool, one result, Paid Partnership label on
- 10% engagement bait in the AI/agent niche

Templates (council-drafted, you post):
1. "Built a 6-agent council for $0.50/run. It routes Grok + Gemini + my relay boxes. Nobody's doing this yet. [result] #ad" + Paid Partnership toggle.
2. "X just killed Revenue Sharing and dropped the bar 10x for Original Content Rewards. If you post AI shit, apply Sep 8. Here's the math."
3. "Stop sending people off-platform. X Money + Subscriptions + affiliates = full stack in one app. Thread."

## Phase 2 — Affiliate stack (pick 3, rotate)
- Agent builders / marketplaces (AITOPIA-style, 70% rev share reported)
- Prompt/agent template packs (your own or curated)
- xAI / Grok API credits (when you upgrade)
High ticket only. $200+/mo SaaS > $15 gadgets.

## Phase 3 — Subscriptions
- Exclusive: full council configs, relay-box blueprints, session logs, unreleased agent prompts.
- Price: $5–15/mo. Tease value in free posts, gate the files.

## Metrics the council tracks
- Verified impressions / 7d (toward 500k bar)
- Affiliate clicks + conversions
- Sub conversions
- Cost per run (cap $0.50 intel)

## Hard no's
- No Linktree, no external Stripe in posts.
- No copied/aggregated content (Original Content Rewards rejects it).
- No posting without Paid Partnership label when money's involved.
- No token upgrades until revenue > cost.
