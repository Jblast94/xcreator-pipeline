🐦 Twitter/X Post

Post via xurl CLI. First-time setup needed:

Setup (run on your machine):
# Install xurl
curl -fsSL https://raw.githubusercontent.com/xdevplatform/xurl/main/install.sh | bash

# Create app at https://developer.x.com/en/portal/dashboard
# Then authenticate:
xurl auth apps add my-app --client-id ID --client-id SECRET
xurl auth oauth2 --app my-app YOUR_HANDLE
xurl auth default my-app

# Verify:
xurl whoami
0/280
After setup, post from terminal: xurl post "text" --media-id ID

⏰ Schedule Posts

Set up automated posting via Hermes cron jobs.

# Schedule a daily morning post (via Hermes CLI):
hermes cron create \
  --name "morning-tweet" \
  --schedule "0 9 * * *" \
  --prompt "Generate and post a tweet about AI/tech trends. Use mcp_grok_chat for text, image-turbo MCP for image, xurl to post to X."

# Schedule a weekly Instagram post:
hermes cron create \
  --name "weekly-insta" \
  --schedule "0 10 * * 1" \
  --prompt "Create an Instagram post about [topic]. Generate image via image-turbo, caption via grok chat."
