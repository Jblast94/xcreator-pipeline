⏰ Schedule a Daily Trend Post

Set up a Hermes cron job that scans trends and posts automatically.

# From Hermes CLI:
hermes cron create \
  --name "daily-trend-post" \
  --schedule "0 9 * * *" \
  --prompt "Search X for top trending topic in AI/crypto/fitness.
Generate: hook tweet, 5-tweet thread, image prompt.
Use image-turbo MCP for image, xurl to post." \
  --skills xurl,social-orchestrator

# Quick schedule (every 6 hours):
hermes cron create \
  --name "niche-scout" \
  --schedule "every 6h" \
  --prompt "Scan X for trending topics in {niche}. Post the best one."
