📋 xAI API Reference

Image Generation:
  POST https://api.x.ai/v1/images/generations
  Model: grok-imagine-image-quality
  Params: prompt, n (1-4), aspect_ratio (1:1, 16:9, 9:16, etc.)

  python:
    from openai import OpenAI
    client = OpenAI(base_url="https://api.x.ai/v1", api_key="xai-...")
    resp = client.images.generate(model="grok-imagine-image-quality", prompt="...")
    print(resp.data[0].url)

Image Editing:
  POST https://api.x.ai/v1/images/edits
  Multipart: image + prompt + model

Video Generation:
  POST https://api.x.ai/v1/videos/generations (async)
  GET  https://api.x.ai/v1/videos/{request_id} (poll)
  Model: grok-imagine-video
  Params: prompt, duration (5-15s), aspect_ratio, resolution (480p/720p/1080p)

  python (auto-polling):
    from xai_sdk import Client
    client = Client()
    resp = client.video.generate(model="grok-imagine-video", prompt="...", duration=10)
    print(resp.url)

Pricing:
  Image: flat per-image cost (see https://docs.x.ai/developers/cost-tracking)
  Video: per-request cost
