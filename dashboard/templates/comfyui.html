📋 ComfyUI Architecture Reference

Standard Image Gen Workflow (FLUX/SDXL):
  Load Checkpoint → CLIP Text Encode (prompt) → KSampler → VAE Decode → Save Image
                                                        ↑
                                              Load Image (for img2img)

Standard Video Gen Workflow (Wan2.1):
  Load Diffusion Model → CLIP Text Encode → Wan Video Sampler → VAE Decode → Save Video
                          ↑                        ↑
                     Load Image (I2V)         Frame Count

FLUX Klein High-Res Workflow:
  Load FLUX Klein → T2I Generation (1024×1024) → Klein Upscale → 4K/8K Output

LoRA Stacking Pattern:
  Load Checkpoint → Load LoRA (unlock @ 0.5) → Load LoRA (style @ 1.0) → ... → KSampler

Recommended Settings:
  Sampler: DPM++ 2M Karras / Euler ancestral
  CFG: 5-7 (FLUX), 7-10 (SDXL), 3.5-5 (photorealism)
  Steps: 28-35 (FLUX), 25-30 (SDXL), 4-8 (Z-Image Turbo)
